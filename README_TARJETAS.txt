MESADA V11 - INTEGRACION DE TARJETAS

Esta versión conserva la aplicación Mesada V11 (base actualizada) y añade la integración visual de las tarjetas proporcionadas por el usuario.

FUNCIONAMIENTO:
- En Cuentas y billeteras se escribe el banco o servicio.
- Mesada reconoce nombres y variaciones comunes (Popular, BanReservas, BHD, Scotiabank, Santa Cruz, APAP/Asociación Popular, AFAPAP, Qik y PayPal).
- Cuando existen varias tarjetas del mismo banco, se puede elegir Crédito, Débito, Gold, Black, Empresarial, Billet o Clásica.
- Mientras se escribe, aparece una vista previa de la tarjeta detectada.
- Al guardar, la asociación queda guardada en la cuenta.
- Las cuentas antiguas que no tengan tarjeta siguen funcionando normalmente.
- Si no hay coincidencia, se muestra el icono normal de la cuenta.

NOTA:
- Las imágenes están incluidas en la carpeta /cards.
- No se modificó la configuración de Supabase ni la lógica de ingresos, pagos, gastos, reportes o recuperación de contraseña.
